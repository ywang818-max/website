One average, three inference questions

Simulated independent waits: Normal(mean 30, SD 5) minutes. No delivery-service records are used. Controls select reproducible, precomputed experiments.

The sample-size choices use nested prefixes of one seeded sample; changing size changes the observations as well as precision. Coverage uses 2,000 entirely new samples, each with 999 bootstrap resamples. Step 1 uses 5,000 resamples; Step 3 uses 50,000 new null-model samples. More simulation draws reduce Monte Carlo noise, not uncertainty in the original data.
