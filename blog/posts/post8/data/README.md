# Simulation inputs, not observed service data

The only build input here is `config.json`. It specifies the complete published
normal teaching model, seed, sample sizes and repetition counts. All observations
and saved statistics under `results/` are generated by `code/build.py`.

There is no real delivery dataset, empirical claim, account, private record or
external download. A normal model is a stylized illustration of waiting times;
its normality/independence assumptions are not established for actual services.

See the project README for independent random streams and the distinction between
resampling one dataset, drawing new population samples for coverage, and drawing
new null-model samples for a hypothesis test. Smaller displayed samples use
prefixes of the same generated base sample. This is disclosed in the UI so a
reader does not treat changing n as holding every observation fixed.
